# Deployment Plan

## Prototype

- Frontend hosted on Vercel or Netlify.
- Backend hosted on Render, Railway, or AWS.
- Database hosted on Supabase, Neon, Railway, or AWS RDS.
- File uploads stored locally or in Cloudinary for demo.

## Production

- Domain-based email configured with SPF, DKIM, and DMARC.
- File uploads stored in AWS S3 or equivalent.
- WhatsApp messaging through approved business API provider.
- Database backups enabled.
- Admin access protected with role-based permissions.

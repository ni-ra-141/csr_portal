# Workflow

## Student Journey

1. Student opens the programme website.
2. Student reads programme details and resources.
3. Student registers with required details and disclaimers.
4. System validates email and mobile through OTP.
5. System checks duplicate email or mobile number.
6. Student receives confirmation email.
7. Team accesses submission and scheduling features when enabled.
8. Team uploads PDF deck and video solution within the submission window.
9. Team books a Regional Round 1 slot from region-specific jury availability.
10. Team receives automated confirmations and updates.

## Admin Journey

1. Admin manages announcements, resources, webinars, and past winners.
2. Admin monitors registrations and duplicate checks.
3. Admin opens or closes submission windows.
4. Admin reviews submissions and scheduling.
5. Admin sends bulk email or WhatsApp updates.
6. Admin maintains FAQ chatbot entries.

## Jury Journey

1. Jury member logs in.
2. Jury marks available time slots.
3. Teams from the assigned region book slots.
4. Jury joins presentation using the linked meeting tool.

# User Roles

## Student

- View programme information.
- Access resources.
- Register and verify OTP.
- Join a team.
- Submit files and book slots.

## Team Leader

- Manage team registration.
- Upload video and PDF deck.
- Book Regional Round 1 slot.

## Admin

- Manage content, registrations, submissions, scheduling, communication, and FAQ data.

## Jury Member

- Add availability.
- View booked teams.
- Join assigned presentation slots.

## Content Manager

- Manage resources, webinars, testimonials, and past winners.
